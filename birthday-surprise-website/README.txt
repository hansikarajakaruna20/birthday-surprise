BIRTHDAY SURPRISE WEBSITE
=========================

1. Open index.html in a browser to preview the site.
2. Replace the placeholder SVG files in /images with your own photos.
   Easiest method:
   - Put your JPG/PNG files in /images
   - Either rename them to photo1.jpg etc. and update index.html paths,
     OR overwrite the SVG placeholders with files of the same names after editing the HTML.
3. Add your song to /music and rename it to song.mp3.
4. Publish the whole folder using GitHub Pages, Netlify, or another static host.

Important interactions already included:
- "NOT YET" goes to the teasing screen.
- "STILL NOT YET" never disappears; it keeps moving when followed/touched.
- "NO" under "Do you love me?" never disappears; it keeps moving even faster.
- Works with mouse and touch/pointer input.
- Responsive for mobile, iPhone, tablet, and desktop.

Tip:
Keep images compressed for fast mobile loading.
